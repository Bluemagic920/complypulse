How ComplyPulse Handles Data & Scope

Four point-in-time Microsoft Graph checks generate a scoped Access Risk Report—not a full organizational HIPAA Security Risk Analysis on their own.

1. Targeted Scope (Not a Full SRA)

ComplyPulse audits selected Microsoft 365 user, guest, and service principal records. A complete HIPAA Security Risk Analysis also requires physical, administrative, and EHR workflow evaluations.

2. Read-Only Graph Permissions

The scan requests read-only Microsoft Graph scopes (User.Read.All, AuditLog.Read.All, Application.Read.All) and does not query EHR databases or email message contents.

3. Point-in-Time Snapshot Runs

Scans run when triggered or reloaded from saved snapshots; unverified tenant runs should be checked against your live Microsoft Entra admin center before relying on them.

4. Dry-Run IT Snippets & Support

Generated PowerShell snippets include -WhatIf so IT staff can inspect actions first and verify retention holds before changing accounts. Support: support@profitharborai.com.
