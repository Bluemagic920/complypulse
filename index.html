Security, Zero-PHI Architecture & Read-Only Graph Permissions

Built for healthcare clinics, regulated SMBs, and external CPA auditors requiring verifiable access-control evidence.

1. Zero PHI / ePHI Exposure

ComplyPulse inspects identity, MFA, and OAuth metadata only—never email bodies, SharePoint files, or patient records—so healthcare teams can run readiness scans immediately.

2. Strictly Read-Only Graph Scopes

Only three read-only application scopes are required: User.Read.All, AuditLog.Read.All, and Application.Read.All. Credentials are held in memory and never stored.

3. Dry-Run (-WhatIf) Remediation

ComplyPulse never modifies your tenant directly. Generated PowerShell scripts default to -WhatIf dry-run mode so admins verify mailbox/litigation holds first.

4. CPA & OCR Audit Packets

Export timestamped CSV control logs and formatted PDF packets mapped to HIPAA, SOC 2, or ISO 27001. Support: support@profitharborai.com.
